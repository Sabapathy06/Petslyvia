> **Work in real life ➔ Fuel your Pet's happiness & evolve your 3D digital companion!**  
> Petslyvia combines daily task management, real-life productivity sprints, computer science education (multi-language coding in Python, JavaScript & C), and real-time multiplayer rooms with a full WebGL 3D virtual pet world.

---

## 🌟 Key Features

### 💻 1. Multi-Language Codespace IDE (Python 3.12, JavaScript & C)
- **Universal Compiler Switching**:
  - 🐍 **Python 3.12**: Modern Python syntax with deterministic loop and directional logic.
  - ⚡ **JavaScript (Node.js 20)**: Real-time ECMAScript execution and array pipeline puzzles.
  - ⚙️ **C (gcc 14.2 / C17)**: High-performance structured C runtime with `#include "petslyvia.h"` and standard I/O.
- **Resilient Language Selector**:
  - React Portal floating dropdown menu with zero CSS clipping across all pages and containers.
  - Dual-mode selector with 1-click quick-switch pills (`🐍 Python`, `⚡ JS`, `⚙️ C`) and native selector fallbacks.
  - Interactive progressive hints, verified solutions, code downloading, and syntax-highlighted snippets.
- **Available Across All Coding Modes**:
  - 🐛 **Bug Dungeon (Bug Detective Mode)**
  - 🧪 **Coding Lab (Matrix & Loop Algorithms)**
  - 🌲 **Adventure Mode (Coder Mode & Visual Queue)**
  - 🎓 **Academy (Concepts & Multi-tab IDE)**
  - 🧱 **Wall Challenge Modals**

---

### 🌐 2. Real-Time Global Multiplayer Arena & Live Rooms
- **Supabase Realtime Presence & Broadcast**:
  - Distributed multiplayer lobbies showing online players, pet avatars, levels, and active areas.
  - Custom room creation (2 to 12 players) with instant shareable links, friend invites, and quick match queuing.
- **Interactive Multiplayer Challenges**:
  - 💥 **Logic Wall Blitz**: Rapid 5-barrier security firewall shootout. Every correct answer shatters a barrier with sound effects, awards +25 XP, and broadcasts live progress (20% ➔ 100%) to all competitors in the room.
  - 🏃 **Crystal Maze Sprint**: Visual programming pathfinding race in a 3D isometric arena. Construct block algorithms, collect crystals (+20 XP), and race to the goal portal in real time.
- **Live Multi-Player Race Tracker**:
  - Real-time progress bars, scores, and walls broken for every player in the room.
  - Instant winner podium fanfare (🥇 Gold crown, XP, and coin rewards).
  - Host match controls with start match, challenge mode switcher, and instant next-round room resets.

---

### 🎮 3. WebGL 3D Engine & Dynamic Camera Controls
- **Interactive 3D Stages**: Low-poly dioramas with real-time lighting, procedural particle systems, and floating platforms.
- **Dynamic Camera Presets**:
  - 📐 **Iso 3D**: Elevated 45° diorama perspective with rich depth.
  - 🎥 **Action 3D**: Dynamic forward-facing cinematic perspective.
  - ⬇️ **Down View (Top-Down)**: Bird’s-eye tactical grid overview for puzzle solving.
  - ✨ **Follow Pet**: Smooth tracking camera following your pet companion in third-person view.
- **Interactive Gestures**: Drag to orbit 360°, scroll to zoom, reset view, and toggle fullscreen 3D.

  - 👑 **Complex** (`-48% Energy`, `+85% Happiness`, `+160 XP`, `+130 Coins`): Milestone architectural implementations.
- **Live Companion Expressions**:
  - ✨ *Super Hyped* (Happiness ≥ 80%)
  - 😊 *Happy & Productive* (Energy ≥ 35% & Happiness ≥ 50%)

  - 😴 *Exhausted / Sleepy* (Energy < 15%)
- **Interactive Cuddling & Reactions**:
  - Click your pet to cuddle, hear cheerful synthesized sounds, and pop floating heart particles.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) / [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sabapathy06/Petslyvia.git
   cd Petslyvia
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
   *(The application automatically operates in standalone offline demo mode if credentials are not provided.)*

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

5. **Build for production:**
   ```bash
   npm run build
   ```

## 🎮 How to Play

1. **Adopt & Name Your Pet**: Choose from 8 unique species (Cat, Fox, Bunny, Dog, Panda, Koala, Hamster, Penguin).
2. **Fuel with Real-Life Tasks**: Open the **Productivity Taskbar** at the bottom-right and check off tasks (stretches, focus sessions, coding) to boost your pet's happiness and earn coins!
3. **Embark on Missions**:
   - Solve pathfinding puzzles in **Logic Forest**.
   - Type code or swap visual blocks in **Bug Dungeon** to fix glitches.
   - Master Python, JavaScript, and C in **Coding Lab**.
4. **Race in Multiplayer Rooms**: Join or create rooms in the **Multiplayer Arena**, choose **Logic Wall Blitz** or **Crystal Maze Sprint**, and race live against other players!
5. **Customize & Expand**: Visit the **Bazaar Shop** to equip wizard hats, cyber visors, and capes.
6. **Create & Share**: Design your own levels in **Creator World** and compete on community tracks!
